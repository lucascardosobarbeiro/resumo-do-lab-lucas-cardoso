💰 Laboratório Azure: Dominando o Gerenciamento de Custos na Nuvem
Este repositório documenta um desafio de projeto da DIO, focado em explorar as ferramentas e estratégias para Gerenciamento de Custos na Microsoft Azure. O objetivo é entender como monitorar, controlar e otimizar os gastos para garantir que o uso da nuvem seja financeiramente sustentável e eficiente.

🎯 O Desafio
O propósito deste laboratório é compreender que a flexibilidade da nuvem vem com a responsabilidade de gerenciar seus custos. O desafio consiste em pesquisar e documentar os principais serviços que a Azure oferece para dar visibilidade, controle e recomendações sobre os gastos, transformando o gerenciamento de custos de uma tarefa reativa para uma estratégia proativa.

Objetivos de Aprendizagem
Ao final deste projeto, fui capaz de:

Identificar as principais ferramentas para análise de custos na Azure.

Entender como criar alertas para evitar gastos inesperados.

Conhecer estratégias para otimizar e reduzir os custos na nuvem.

Diferenciar os modelos de precificação e as opções de desconto.

💸 Pilares do Gerenciamento de Custos na Azure
A Azure oferece um conjunto de ferramentas integradas para ajudar a controlar os gastos em todas as fases do ciclo de vida de um projeto.

1. Azure Cost Management + Billing
É o hub centralizado para a gestão financeira na Azure. Pense nele como o painel de controle financeiro do seu ambiente. Ele permite:

Analisar Custos: Visualizar dashboards detalhados que mostram onde o dinheiro está sendo gasto (por serviço, por recurso, por tags).

Monitorar Tendências: Acompanhar os gastos ao longo do tempo para prever custos futuros.

Exportar Dados: Agendar exportações de dados de custo para análise em outras ferramentas.

2. Azure Advisor
Funciona como um consultor de nuvem personalizado e gratuito. O Advisor analisa o uso dos seus recursos e fornece recomendações proativas para otimizar o ambiente em várias áreas, mas seu papel no controle de custos é fundamental:

Recomendações de Custo: Sugere ações concretas para economizar, como redimensionar ou desligar VMs subutilizadas, ou comprar instâncias reservadas para cargas de trabalho estáveis.

3. Azure Budgets (Orçamentos)
É a principal ferramenta para controle proativo de gastos. Com os orçamentos, você pode:

Definir Limites: Estabelecer um teto de gastos para uma assinatura, um grupo de recursos ou uma tag específica.

Receber Alertas: Configurar notificações por e-mail quando os gastos atingem um determinado percentual do orçamento (ex: 50%, 80%, 100%). Isso permite tomar ações antes que os custos saiam do controle.

4. Azure Reservations (Reservas)
Uma estratégia financeira para reduzir custos significativamente em cargas de trabalho previsíveis.

Compromisso de Longo Prazo: Você se compromete a usar um determinado serviço (como Máquinas Virtuais ou Bancos de Dados SQL) por um período de um ou três anos.

Descontos Expressivos: Em troca desse compromisso, você recebe um grande desconto em comparação com os preços de pagamento conforme o uso (pay-as-you-go).

✨ Conclusão
Este estudo demonstrou que o gerenciamento de custos na Azure é uma disciplina contínua e essencial. Utilizando o Cost Management para visibilidade, o Advisor para obter insights, os Budgets para controle e as Reservations para otimização, é possível aproveitar todo o poder da nuvem de forma financeiramente inteligente e sustentável.
